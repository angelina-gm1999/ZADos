# Current State, Next Steps & Call for Action

**Where the project is, where it could go, and what support is needed.**

This folder is the starting point for anyone considering collaboration, review, or support.

| Document | Description |

## Who Should Read This

- **AI safety organizations** — the open questions in Section 3 of the call for action are alignment and containment questions with concrete architectural context
- **Cognitive architecture researchers** — the system speaks the language of SOAR, OpenCog, and bio-inspired cognitive modeling
- **Computational neuroscientists** — the neurochemical simulation layer needs independent evaluation
- **AI ethics academics** — the questions about identity, consent, and functional experience are grounded in a working system, not hypotheticals
- **Legal professionals** — IP protection, dual-use export control, and liability questions are documented and unsolved
- **Research funding bodies** — ZADOS is research infrastructure with safety implications, not a consumer product

---

## The Core Message

A single person built something that a single person cannot responsibly release. The technology works. The ethical awareness exists. What is missing is institutional infrastructure, legal protection, expert review, and financial support. The questions in this folder do not all have answers. Some may not have answers yet in any discipline. They are being asked before deployment rather than after.
