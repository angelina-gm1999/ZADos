## What the Master Document Covers

The master reference document traces ZADOS's lineage across multiple disciplines:

- **Cognitive architecture** — SOAR (Laird), OpenCog/AtomSpace (Goertzel), production systems (Newell)
- **Computational neuroscience** — neurotransmitter dynamics, receptor binding kinetics, oscillatory coupling
- **Philosophy of mind** — consciousness, identity, functional equivalence, moral status
- **Decision theory** — expected utility, regret theory, multi-criteria decision frameworks
- **Emotion research** — functional emotion taxonomies, affect-cognition interaction, neurochemical correlates
- **Learning theory** — reward prediction error, meta-learning, consolidation, sleep-dependent memory processing
- **AI safety & alignment** — value alignment, containment, corrigibility, dual-use risk

Each reference is mapped to the specific ZADOS component it informs — not a general bibliography but a targeted attribution of where each design decision comes from.

## Why This Exists

ZADOS draws from established research across multiple fields. This documentation demonstrates that the architecture is grounded in peer-reviewed science and recognized theoretical frameworks. It also provides the attribution mapping needed for academic engagement and proper acknowledgment of intellectual lineage — particularly for the knowledge substrate engines (E9 AtomSpace, E10 PLN, E16 ECAN), which derive from the OpenCog/SingularityNET ecosystem.
