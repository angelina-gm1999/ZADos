## The Arc

The development history follows a clear sequence:

1. **Conceptual validation** (valuem) — a single-file prototype proving the core thesis: that structural pattern detection + neurochemical simulation + reward evaluation produces emergent cognitive behavior. It worked. Then it broke.
2. **Design phase** — ~900 pages of specifications produced through parallel research tracks: cognitive science and neuroscience as external references, introspective metacognitive analysis as internal reference.
3. **Implementation** — 37+ development sessions building the current architecture: 350+ source files, 29 cognitive engines, 12-NT neurochemical simulation, 3-tier memory, 4-domain reward system, 6,135+ passing tests.

The pre-development materials document phases 1–2. The logs document phase 3.
